# Constrain owner-authored profile visuals

Profile showcase components, layout renderers, visual token schemas, decoration slots, and reusable effect behaviors remain code-owned, while the owner may assemble Profile Skins from validated tokens and managed media, upload compatible image-based Profile Decorations, select registered effects, and manage catalog metadata, availability, VIP requirements, Eteris prices, and ordering. This gives the owner useful catalog control without accepting arbitrary CSS, HTML, or JavaScript; adding new rendering capabilities still requires a deployment.
